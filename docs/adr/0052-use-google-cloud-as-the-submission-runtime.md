# ADR 0052: Use Google Cloud as the submission runtime

For the All Things Agentic Hackathon submission, Unstuck will use one active runtime built with Genkit, a configured Gemini model on Vertex AI (default `gemini-3.5-flash`), Cloud Run, Firebase Authentication, Firestore, and private temporary Cloud Storage. This supersedes the provider-specific platform choices in ADRs 0004-0006, 0013-0014, 0037-0038, 0041-0043, and 0050-0051; a dual-provider runtime was rejected because it would multiply failure modes and obscure the required Google Cloud architecture while preserving little product value.
