# Use feedback-gated situational Pivot mini-plans

The Pivot guide will keep its application-owned five-kind Pivot library, but Gemini may tailor the concrete action, duration, and smaller fallback to the current Situation map. After a person selects an action, the guide generates at most three sequential steps and waits for explicit feedback before each next step. When the person opts into saving, the completed protocol state and Derived memory retain the selected action and final outcome, but discard unused recommendation alternatives, mini-plan actions, and step-feedback history. Unsaved protocol state is temporary working state only: it is excluded from saved history, expires after 24 hours, and never creates a Derived memory. This gives the agent a practical adaptive loop without turning Unstuck into an unbounded task planner or granting it external side effects.
