# Use feedback-gated situational Pivot mini-plans

The Pivot guide will keep its application-owned five-kind Pivot library, but Gemini may tailor the concrete action, duration, and smaller fallback to the current Situation map. Grounding, breathing-focus, reaching-out, and basic-needs-reset actions remain short; a task-first-step action may be a detailed work-oriented action of up to 60 minutes with up to six ordered steps, using only explicit deadlines, criteria, point values, constraints, and dependencies from the Situation map. After a person selects an action, the guide generates at most three sequential mini-plan actions and waits for explicit feedback before each next action. When the person opts into saving, the completed protocol state and Derived memory retain the selected action and final outcome, but discard unused recommendation alternatives, mini-plan actions, and step-feedback history. The one bounded exception is a derived `blocked` cautionary signal: if any mini-plan step was reported blocked, the Derived memory retains that one bit so a future Check-in can treat the Pivot as a Cautionary prior pattern, but the underlying step-by-step feedback (which step, its note, its order) is never retained. Unsaved protocol state is temporary working state only: it is excluded from saved history, expires after 24 hours, and never creates a Derived memory. This gives the agent a more useful work-planning loop without turning Unstuck into an unbounded task planner or granting it external side effects.
