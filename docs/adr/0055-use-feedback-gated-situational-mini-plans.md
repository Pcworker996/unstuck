# Use feedback-gated situational Pivot mini-plans

The Pivot guide will keep its application-owned five-kind Pivot library, but Gemini may tailor the concrete action, duration, and smaller fallback to the current Situation map. After a person selects an action, the guide generates at most three sequential steps, waits for explicit feedback before each next step, and retains only the selected action and final outcome when the person has opted into memory. This gives the agent a practical adaptive loop without turning Unstuck into an unbounded task planner or granting it external side effects.
