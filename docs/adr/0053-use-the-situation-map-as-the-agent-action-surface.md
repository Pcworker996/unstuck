# ADR 0053: Use the situation map as the agent action surface

The pivot guide will perform autonomous work by creating and revising a person-editable situation map whose user statements, artifact-derived claims, and agent interpretations retain distinct provenance. The person continues to choose and carry out pivots; external actions are excluded from the core protocol, with only an optional, explicitly confirmed calendar time block permitted, because visible data transformation and bounded authority fit a collaborative self-regulation companion better than uncontrolled task execution.
